# Install Flowbot

Flowbot runs in Docker, so it installs the same way everywhere. Pick the guide for your computer:

| System | Guide | Best for |
|---|---|---|
| Linux | [install-linux.md](install-linux.md) | Running Flowbot for a live website |
| macOS | [install-macos.md](install-macos.md) | Trying Flowbot and building bots |
| Windows | [install-windows.md](install-windows.md) | Trying Flowbot and building bots |

Each guide takes about 10 minutes. Whatever the system, you need:

- Docker with Docker Compose v2
- At least 2 CPU cores, 2 GB RAM and 5 GB free disk
- About 640 MB of downloads for the routing model, plus the Flowbot image

Your bots, flows and settings move with you. To go from your laptop to a server, [back up](backup.md) on one and restore on the other.
